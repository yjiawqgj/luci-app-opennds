# 2026-11-11

## OpenNDS 网络区域识别（登录模式3）：分发脚本 + LuCI 插件

需求：按客户端所在无线 SSID / 有线接口提供不同认证门户；LuCI 界面参考根目录 `网络区域识别.html` 演示布局。

开发前已向用户确认 4 项：现代 JS LuCI；区域下拉框=切换登录模式1/3（应用时写回 openNDS 配置）；各区域门户路径独立无共用冲突；"标记"=未选特定门户即使用 default/default.sh。

### 交付物（`zone-detect/` 目录，OpenWrt 根文件系统结构）
- `usr/lib/opennds/theme_zone_detect.sh` — 分发脚本（Mode 3 themespec）：get_client_interface.sh → iw dev 判无线 → uci 查 SSID（phyN-apM → radioN 第M个ap）→ 门户查找链：标记默认 → `<SSID>.sh` → `<SSID>/theme.sh` → `default/default.sh` → 官方回退主题。
- `usr/lib/opennds/zone-api.sh` — LuCI 后端（rpcd file.exec 调用，子命令输出单行 JSON）：status/uploaded/upload_begin/upload_mkdir/upload_store/upload_delete/unmatched_list/unmatched_delete/save_cache/apply。
- `usr/www/luci-static/resources/view/zone_detect/zone.js` — JS 视图（按演示 HTML 布局：区域选择/无线卡片/有线卡片/上传/已上传/未匹配/保存缓存/应用）。
- `usr/share/luci/menu.d/luci-app-zone-detect.json`、`usr/share/rpcd/acl.d/luci-app-zone-detect.json`、`etc/config/zone_detect`（缓存 uci）。
- `usr/lib/opennds/sample_default.sh` — default/default.sh 示例门户。

### 关键设计
- 上传改名映射：上传后存为 `<原名>1[.sh]` 并写 `<区域>/.portal_map`（tab 分隔 orig→stored）；下拉框显示原名；应用时改名 `<SSID>.sh` / `<SSID>/`，切换门户时旧应用门户恢复原名。
- 状态文件：`zone_markers`（默认区域标记，分发脚本读取）、`zone_applied`（应用记录）、`.portal_map`（映射）。
- 保存=写 uci `zone_detect` 缓存；应用=改名+写标记+写 `opennds` 的 login_option_enabled/themespec+重启 opennds。
- 禁用/重名 SSID 卡片不可配置；未匹配 = wireless/wired 根目录下不属于当前 SSID/管理接口的条目。

### 测试
用 stub（uci/iw/ndsctl/ip/get_client_interface）做了冒烟测试：status/上传改名/重复拦截/长度限制/保存/应用/恢复/未匹配/删除使用中拦截/路径穿越拦截；分发脚本四种路径（应用门户、标记默认、默认回退、有线/未知回退）及含空格 SSID 全部通过。期间修复了 `cmd_uploaded` 中 bad_name 判断反相和 restore_applied 扩展名重复两个真实 bug。沙箱曾因 get_client_interface.sh stub 位置放错导致误判，实际代码无问题。

### 已知限制
- 上传仅支持文本文件（fs.write 文本）；门户目录里如需图片等二进制资源需手动放置。
- 名称长度按字节计数（busybox awk），中文名约 6 字上限。
- phyN-apM → uci wifi-iface 顺序映射依赖 uci 配置顺序与运行时编号一致（主流 OpenWrt 成立）。
