## 客户端豁免管理：按区域自动豁免（openNDS）

实现了「客户端接入不同网络区域 → 按豁免页配置决定是否信任/预授权」的完整链路，交付在
`zone-detect/`（与之前的区域识别插件同一目录，可直接叠加安装）。

### 新增文件
- `usr/lib/opennds/zone_lib.sh` — 共享库：SSID/接口识别、`ndsctl json` 解析、租约/ARP 查询。
  `theme_zone_detect.sh`、`zone_exempt.sh`、`exempt-api.sh` 共用，避免三份实现漂移。
- `usr/lib/opennds/zone_exempt.sh` — 豁免引擎：`apply <mac> [type] [zone]` / `scan` / `revoke` / `state`。
  规则读 `/etc/config/zone_exempt`（一次性读入 shell 变量），运行态写 `/tmp/zone_exempt.state`。
- `usr/lib/opennds/zone_exemptd.sh` + `etc/init.d/zone-exempt` — procd 守护，默认 2s 轮询。
- `etc/hotplug.d/dhcp/90-zone-exempt` — DHCP 租约事件立即评估，先于门户弹出。
- `usr/lib/opennds/exempt-api.sh` — LuCI 后端（status/clients/apply/scan）。
- `usr/www/luci-static/resources/view/zone_detect/exempt.js` — 豁免页视图（按演示 HTML 布局）。
- `etc/config/zone_exempt`、`etc/uci-defaults/95-zone-exempt`；menu.d / acl.d 增加第二个节点。

### 关键机制（重要）
- **运行时信任**：`ndsctl trust/untrust`（openNDS ≥10 才有，引擎用 `ndsctl -h` 探测；不支持则退回
  `ndsctl auth` 预认证并提示）。
- **运行时预授权**：`ndsctl auth <mac>`，保留流量统计/配额/会话管理；`ndsctl` 效果不跨重启，
  引擎用 `pidof opennds` 变化检测重启 → 清空 state 后重新评估。
- **不是 ndsctl json 里的 clientif**：桥接无线客户端的 clientif 是 br-lan，必须用
  `get_client_interface.sh`（iw station dump）判定无线，否则会把无线客户端当有线。
- **竞争兜底**：`theme_zone_detect.sh` 在出示门户前调用引擎，命中豁免就直接 `ndsctl` 放行并返回
  meta refresh 跳转页，避免「门户闪一下」。
- **应用时机**：只有在 `allow_preemptive_authentication` 真的变化时才重启 openNDS，其余只重新评估。

hotplug 触发、分发脚本豁免与门户两条路径。全部通过。
