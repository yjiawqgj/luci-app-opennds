### 需求A 关不掉/开/关横跳（真机）
- 现象：点关闭后按钮在开/关间反复横跳；终端 `service opennds status` 显示 not running，再手动敲一次 `service opennds stop` 才 inactive、页面才稳定。
- 根因查证：页面判 running 用 `nds_running()`=pidof/`/proc` 进程名；`service status` 是 procd instance 状态，两套判据。opennds 官方 init（linux_openwrt/opennds/files/etc/init.d/opennds）：`respawn 360 20 15`、`term_timeout 90`、`service_stopped()` 等 pidof 最多10s 再 delete_chains；主程序 conf.c:164 读 enabled!=1 就 exit(0)。点关闭时 enabled=0 已 commit → 主进程自退 → procd 当意外退出反复拉起；旧 toggle_exec 的 stop 只等 pidof 空一次就返回，没确认实例真关掉 → 进程时有时无 → 页面 5s 轮询撞上就横跳。
- 修法：新增 `stop_fully()`（api.sh ~5817）替换 toggle_exec want=0 分支。stop → 稳定确认连续 `CPD_STOP_STABLE`(默认5s) 无进程才算停透；观察期进程又出现（respawn）→ 再补一次 stop（等价用户手动补敲那次），最多 `CPD_STOP_ROUNDS`(默认3) 轮；多轮仍不退才 kill + delete_chains。只影响停止分支，启动走 start/重启走 service_restart 均未动。
- 测试：t15 新增 C11，用自定义 pidof/init 桩模拟「第一次 stop 后进程被 respawn 拉回、第二次 stop 才停透」，断言补停次数≥2、进程退出、终态 running:0。lib.sh 加 `CPD_STOP_STABLE=1`/`CPD_STOP_ROUNDS=2` 沙箱加速。

### 需求B 黄灯过渡态（纯前端 overview.js）
- 用户口径：点关闭二次确认后到真正生效那几秒，按钮变黄、标题「正在关闭」，下一轮轮询确认关闭后再显示红「未运行」；开启同理黄「正在启动」→绿「运行」（文案沿用演示的"运行"，未改"正在运行"）。
